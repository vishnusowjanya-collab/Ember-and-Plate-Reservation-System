# Ember-and-Plate-Reservation-System
Premium Full-Stack Restaurant Table Reservation System
## 🚀 Tech Stack Used
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** Oracle Database 21c Express Edition

## 🛠️ Project Structure
- `index.html` - Premium UI with Image Slider and Tab Switching
- `server.js` - Express backend with Oracle DB pool connection endpoints
- `script.js` - Handles client-side API requests and live grid matching logic

## 💻 How to Setup and Run
1. Open **Oracle SQL*Plus** and run the `CREATE TABLE reservations` script to setup the database schema.
2. Open terminal inside the project folder and run:
   ```bash
   npm install
   ```
3. Start the backend architecture server:
   ```bash
   node server.js
   ```
4. Double-click `index.html` to launch the premium dining application in your browser!
